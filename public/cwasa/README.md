# CWASA Assets

Place the browser-compatible CWASA/JASigning HTML5 files here.

Expected structure:

```txt
public/cwasa/
  cwa/
    allcsa.js
    cwasa.css
    cwacfg.json
  avatars/
  avjson/
  sigml/
  cwasa-test.html
```

After adding the files, run the app and open:

```txt
http://localhost:3000/cwasa/cwasa-test.html
```
